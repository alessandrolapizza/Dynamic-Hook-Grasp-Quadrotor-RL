# CAD files

The two files below describe the quadrotor used in this project. They were used to estimate its inertia.

| File | Content |
|---|---|
| `OmniNxt-hook-grasp-rl.step` | The quadrotor, derived from the CAD of the open-source [OmniNxt](https://github.com/HKUST-Aerial-Robotics/OmniNxt) (HKUST Aerial Robotics Group) and modified to match our drone. |
| `Propeller.step` | The drone's propeller, modelled for this project. |

Both files are stored with [Git LFS](https://git-lfs.com/).
